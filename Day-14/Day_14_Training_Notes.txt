The RTF reporting task continued during Day 14.

1. RTF based on a Master-Detail Report.

2. RTF based on a Parameterized Report.


==================================================
2. MASTER-DETAIL REPORT
==================================================

For the Master-Detail Report, the report style can be:

- Group Above
- Group Left

Example query:

SELECT *
FROM EMP, DEPT
WHERE EMP.DEPTNO = DEPT.DEPTNO;


The Query Builder example included fields from both
DEPT and EMP.

Example:

DEPT.DEPTNO
DEPT.DNAME
DEPT.LOC
EMP.EMPNO
EMP.ENAME
EMP.JOB
EMP.MGR
EMP.HIREDATE
EMP.SAL
EMP.COMM
EMP.DEPTNO

5. PARAMETERIZED REPORT
==================================================

The Parameterized Report uses:

SELECT *
FROM EMP
WHERE DEPTNO = :DNO;

:DNO is a Bind Parameter.

The parameter is used to filter employees according
to the selected DEPTNO.

21. TRIGGERS IN ORACLE FORMS
==================================================

A Trigger executes automatically when a specific event
occurs.

Forms Triggers discussed:

1. WHEN-NEW-FORM-INSTANCE

2. WHEN-NEW-ITEM-INSTANCE

3. WHEN-VALIDATE-ITEM


==================================================
22. WHEN-NEW-FORM-INSTANCE
==================================================

WHEN-NEW-FORM-INSTANCE fires when the Form enters
runtime.

Concept:

Form Starts Runtime
        ↓
WHEN-NEW-FORM-INSTANCE
        ↓
Trigger Fires


==================================================
23. WHEN-NEW-ITEM-INSTANCE
==================================================

WHEN-NEW-ITEM-INSTANCE fires when the cursor enters
an Item or Field.

Concept:

Cursor Enters Item
        ↓
WHEN-NEW-ITEM-INSTANCE
        ↓
Trigger Fires


==================================================
24. WHEN-VALIDATE-ITEM
==================================================

WHEN-VALIDATE-ITEM fires when an Item value is changed
and the Item is validated.

Example:

SAL = 3000

Change SAL to:

SAL = 9000

The Item value changes and validation occurs.

WHEN-VALIDATE-ITEM fires.


==================================================
25. REPORT TRIGGERS
==================================================

Five Report Triggers were discussed:

1. Before Parameter Form

2. After Parameter Form

3. Before Report

4. Between Pages

5. After Report


==================================================
26. BEFORE PARAMETER FORM
==================================================

This Trigger fires before the Parameter Form is displayed
and before the user enters report parameter values.

Example:

A DEPTNO parameter is defined for a report.

Before asking the user to enter DEPTNO:

Before Parameter Form
fires.


==================================================
27. AFTER PARAMETER FORM
==================================================

This Trigger fires after the report parameter values
have been entered.

Example:

User enters DEPTNO.

After Parameter Form
fires.


==================================================
28. BEFORE REPORT
==================================================

Before Report fires before the report is executed
and displayed.

Concept:

Parameters Completed
       ↓
Before Report
       ↓
Report Runs


==================================================
29. BETWEEN PAGES
==================================================

Between Pages fires between report pages.

It is triggered before the next report page is
displayed.


==================================================
30. AFTER REPORT
==================================================

After Report fires after report processing is completed.

It is the final Report Trigger in the report trigger
sequence.


==================================================
31. REPORT TRIGGER SEQUENCE
==================================================

The Report Triggers discussed were:

Before Parameter Form
        ↓
After Parameter Form
        ↓
Before Report
        ↓
Between Pages
        ↓
After Report

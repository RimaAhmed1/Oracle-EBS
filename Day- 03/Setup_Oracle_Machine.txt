SETUP ORACLE MACHINE

Objective:
Set up and access the Oracle training environment required for
Oracle EBS technical development.

--------------------------------------------------
STEPS
--------------------------------------------------

1. Access the provided Oracle training machine.

2. Log in using the credentials provided for the training
   environment.

3. Verify that the Oracle development environment is available.

4. Open SQL*Plus.

5. Connect to the Oracle Database.

6. Verify the connected database user using:

   SHOW USER;

7. Verify the database connection by executing:

   SELECT SYSDATE FROM DUAL;

8. Open SQL Developer.

9. Configure the Oracle Database connection using the required
   connection details:

   - Username
   - Password
   - Hostname
   - Port
   - Service Name

10. Test the connection.

11. Open Oracle Forms Builder and verify that it is available.

12. Open Oracle Reports Builder and verify that it is available.

--------------------------------------------------
TOOLS USED
--------------------------------------------------

- Oracle SQL*Plus
- Oracle SQL Developer
- Oracle Forms Builder
- Oracle Reports Builder

--------------------------------------------------
RESULT
--------------------------------------------------

The Oracle training machine was accessed successfully and the
required Oracle development tools were verified and ready for
Oracle EBS technical development.

--------------------------------------------------
VERIFICATION
--------------------------------------------------

The Oracle Database connection was verified successfully
using SQL*Plus.

Commands Used:

SHOW USER;

SELECT SYSDATE FROM DUAL;

The SHOW USER command confirmed that the connected database
user is APPS.

The SYSDATE query returned the current database date,
confirming that the Oracle Database connection was working
successfully.

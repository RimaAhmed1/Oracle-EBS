--------------------------------------------------
NULL VALUES
--------------------------------------------------

NULL represents the absence of a value.

To check for NULL values, IS NULL is used.

Correct:

SELECT *
FROM EMP
WHERE COMM IS NULL;

Incorrect:

SELECT *
FROM EMP
WHERE COMM = NULL;


--------------------------------------------------
ORACLE FORMS
--------------------------------------------------

Oracle Forms Builder is used to develop Forms that allow
users to interact with data stored in the Oracle Database.

The basic relationship is:

Database Table  -> Data Block
Table Column    -> Item
Table Row       -> Record


A Form can contain:

Form Module
    |
    +-- Window
         |
         +-- Canvas
              |
              +-- Data Blocks
                   |
                   +-- Items


--------------------------------------------------
DEPT AND EMP MASTER-DETAIL
--------------------------------------------------

The DEPT and EMP tables can be used to create a
Master-Detail Form.

Master Block:
DEPT

Detail Block:
EMP

Relationship:

DEPT.DEPTNO = EMP.DEPTNO

--------------------------------------------------
PL/SQL PROCEDURE
--------------------------------------------------

A Procedure is a named PL/SQL program unit used to perform
a specific operation.

Example:

CREATE OR REPLACE PROCEDURE RIMA_PR_TEST
IS
BEGIN
    DBMS_OUTPUT.PUT_LINE('WELCOME TO ORACLE PROCEDURE');
END;
/

To execute:

SET SERVEROUTPUT ON;

EXEC RIMA_PR_TEST;


--------------------------------------------------
PL/SQL FUNCTION
--------------------------------------------------

A Function is a named PL/SQL program unit that returns
a value.

Example:

CREATE OR REPLACE FUNCTION RIMA_FN_TEST
RETURN VARCHAR2
IS
BEGIN
    RETURN 'WELCOME TO ORACLE FUNCTION';
END;
/

The Function can be called using:

SELECT RIMA_FN_TEST
FROM DUAL;


--------------------------------------------------
PROCEDURE VS FUNCTION
--------------------------------------------------

Procedure:
Performs an operation.

Function:
Returns a value.

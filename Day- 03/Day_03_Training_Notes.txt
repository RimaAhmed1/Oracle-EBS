--------------------------------------------------
ORACLE EBS USER
--------------------------------------------------

Oracle EBS users are created and managed through the
System Administrator responsibility.

Navigation:

System Administrator
> Security
> User
> Define

A user can be assigned one or more Responsibilities
depending on the required application access.


--------------------------------------------------
RESPONSIBILITY
--------------------------------------------------

A Responsibility controls the functions, forms, reports
and other Oracle EBS features that a user can access.

Examples:

- System Administrator
- Application Developer


--------------------------------------------------
QUERY BY EXAMPLE (QBE)
--------------------------------------------------

Query By Example is used to search for records in
Oracle EBS Forms.

Steps:

1. Open the required Form.

2. Navigate to:

   View > Query By Example > Enter

3. Enter the search criteria.

Example:

   RIMA%

4. Navigate to:

   View > Query By Example > Run

5. Verify the returned records.


--------------------------------------------------
ORACLE DATABASE CONNECTION
--------------------------------------------------

Oracle SQL Developer can be used to connect to the
Oracle EBS database.

Common connection information includes:

- Username
- Password
- Hostname
- Port
- Service Name

The Service Name identifies the Oracle Database service
used for the connection.


--------------------------------------------------
ORACLE DEVELOPMENT TOOLS
--------------------------------------------------

The Oracle training environment provides tools used for
Oracle EBS technical development, including:

- SQL Developer
- SQL*Plus
- Oracle Forms Builder
- Oracle Reports Builder


--------------------------------------------------
ORACLE EBS DATABASE
--------------------------------------------------

Oracle EBS uses an Oracle Database to store application
data.

The EBS database contains a large number of predefined
tables used by different Oracle EBS modules.

Application data can be queried using SQL when the
appropriate database access is available.

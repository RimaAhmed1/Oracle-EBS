Key Concepts:

- Data:
  Raw facts that have not yet been processed.

- Information:
  Processed and organized data that has meaning.

- Database:
  An organized collection of related data.

- Primary Key:
  A column or combination of columns that uniquely identifies
  each record in a table.

- Foreign Key:
  A column that creates a relationship between two tables by
  referencing a Primary Key in another table.

- Composite Primary Key:
  A Primary Key consisting of more than one column.

SQL Categories:

- DDL - Data Definition Language
  Examples: CREATE, ALTER, DROP

- DML - Data Manipulation Language
  Examples: INSERT, UPDATE, DELETE

- DQL - Data Query Language
  Example: SELECT

- DCL - Data Control Language
  Examples: GRANT, REVOKE

ERP:
ERP stands for Enterprise Resource Planning.
It is an integrated system used to manage different business
processes using a common system and database.

Oracle EBS:
Oracle E-Business Suite (EBS) is an ERP application suite
used by organizations to manage different business functions.

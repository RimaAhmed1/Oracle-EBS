DAY 13 - TRAINING NOTES
Oracle EBS Technical Training

Topic:
BIP - Business Intelligence Publisher / XML Publisher Reports


==================================================
1. ORACLE REPORTS VS BI PUBLISHER
==================================================

Oracle Reports:

- Accesses data from Oracle Database.
- Used as a reporting tool for Oracle data.


BI Publisher:

- Can access data from multiple data sources.
- Can work with different ERPs and databases.
- Can generate output in multiple formats.
- Can deliver reports to multiple destinations.
- Runs through the BI Publisher Server.
- Can be accessed using a URL.
- Can create reports using Subject Areas.
- Supports desktop tools for report design.

Examples of Desktop Tools:

- Microsoft Word
- Microsoft Excel
- Adobe


==================================================
2. BI PUBLISHER
==================================================

BI Publisher is used for delivering high-fidelity,
pixel-perfect reports in multiple formats.

It separates:

Data
    ↓
Template
    ↓
Output
    ↓
Destination

==================================================
4. BURSTING
==================================================

Bursting is a process of generating multiple documents
from a batch report and delivering the documents to
multiple destinations.

Concept:

Batch Report
    ↓
Generate Documents
    ↓
Multiple Outputs
    ↓
Multiple Destinations


==================================================
5. BI PUBLISHER SERVER
==================================================

BI Publisher can be accessed through the BI Publisher Server.

General access pattern:

http://<Company URL>:7001/xmlpserver

The BI Publisher Home Page provides access to the Catalog.


==================================================
6. BI PUBLISHER CATALOG
==================================================

The Catalog contains folders used to organize BI Publisher
objects.

Two important folder types:

Shared Folders:

- Public/shared area.
- Can be accessed by multiple users depending on permissions.


My Folders:

- Private area.
- Used for a user's own BI Publisher content.

13. DESIGN REPORT USING MICROSOFT WORD
==================================================

General process:

1. Open Microsoft Word.

2. Open the BI Publisher Ribbon.

3. Load Sample XML.

4. Use Table Wizard.

5. Select the required fields.

6. Configure grouping.

7. Configure sorting.

8. Complete the layout.

9. Save the template as .rtf.

10. Preview the report.

==================================================
19. PARAMETERIZED REPORT
==================================================

The Parameterized Report uses the query:

SELECT *
FROM EMP
WHERE DEPTNO = :DNO;

:DNO is a Bind Parameter.

The value entered for DNO determines which department's
employees are returned.
